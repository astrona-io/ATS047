# Push vs Pull

This section covers push vs Pull. It develops pull Scraping, Push Delivery And Short-Lived Jobs through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Compare pull collection with producer-initiated delivery.
- Explain target health evidence in the scrape model.
- Identify the intended Pushgateway use case and lifecycle risks.
- Distinguish remote write from application exposition.
