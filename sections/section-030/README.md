# Tracing and Spans

This section covers distributed tracing for the observability concepts domain. It has two modules. The first follows one request through two services and teaches spans, the `traceparent` header, parent-child links, self time, context propagation and the care needed with span attributes. The second teaches sampling, the reasons spans go missing, exemplars, and how to move from a metric to a trace and a log line.

Each module has a landing page, readings with hands-on steps in a private playground, a graded lab and a summary. The section ends with a capstone lab and a knowledge check.

## Learning Outcomes

- Explain trace and span identity and timing.
- Distinguish parent-child structure from a complete causal explanation.
- Describe context propagation across service boundaries.
- Account for sampling, missing spans and sensitive attributes.
- Explain exemplars and use them to move from a metric to a trace.
