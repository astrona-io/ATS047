# Tracing and Spans

This section covers tracing and Spans. It develops tracing Requests Through Spans And Context through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Explain trace and span identity and timing.
- Distinguish parent-child structure from a complete causal explanation.
- Describe context propagation across service boundaries.
- Account for sampling, missing spans and sensitive attributes.
