# Understand logs and events

This section covers understand logs and events. It develops logs And Events As Evidence Beside Metrics through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Distinguish numerical series from individual event records.
- Design structured records with useful identity and timing.
- Correlate logs with metrics without confusing correlation with cause.
- Account for retention, sampling and sensitive data.
