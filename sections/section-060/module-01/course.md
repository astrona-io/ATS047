# Service Indicators, Objectives, Agreements And Budgets

This module develops service Indicators, Objectives, Agreements And Budgets. Use the explanations to connect intended behavior with responsible components and observable evidence.

## Learning Goals

- Distinguish an SLI, SLO and SLA.
- Define good and valid event populations and an evaluation window.
- Calculate an error budget and interpret burn rate.
- Account for low traffic, exclusions and incomplete observation.

## Before You Start

Examples illustrate declared relationships and reasoning. No execution environment is required or claimed.
