# Basics of SLOs, SLAs, and SLIs

This section covers basics of SLOs, SLAs, and SLIs. It develops service Indicators, Objectives, Agreements And Budgets through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Distinguish an SLI, SLO and SLA.
- Define good and valid event populations and an evaluation window.
- Calculate an error budget and interpret burn rate.
- Account for low traffic, exclusions and incomplete observation.
